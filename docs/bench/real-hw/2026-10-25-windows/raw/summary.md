## 說明與限制

- 情境與量法同 Linux 版（gpui-xq-demo/scripts/bench-*.sh）。記憶體：Working Set（≈ Linux RSS）、Working Set - Private（≈ 工作管理員「記憶體」欄）、Private Bytes（commit）。
- GPU 使用率來自效能計數器 GPU Engine（3D 引擎、這棵程序樹、每秒取樣平均）；抓不到時顯示 —。雙顯卡筆電請確認 app 跑在哪張卡（設定 → 系統 → 顯示器 → 圖形）。
- 點選切換：腳本先把滑鼠移到報價表 2330／2317 列上（座標 × DPI 縮放），停 0.1 秒再按；延遲從按下算起。仍有 missed 時看截圖確認是否點歪。
- 測試期間不要動滑鼠鍵盤；其他程式（瀏覽器、Teams、防毒掃描）會影響 CPU 與延遲。原始數據在 results.json，各 app 輸出在 *.log。
