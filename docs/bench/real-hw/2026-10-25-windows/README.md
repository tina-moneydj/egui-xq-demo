## 結論先看

1. **多視窗延遲修好了，Windows 也「勉強通過」。** 4 個視窗（兩個螢幕）GPUI 延遲 p99 **64.3 → 36.0 ms**、p50 **43 → 31 ms**，FPS 57–58 → 60。egui OpenGL 33.4 ms、egui wgpu 33.9 ms。差 2–3 ms，約 0.2 幀，肉眼看不出來。
2. **但效率還是 egui 明顯較好，這次沒有改善。** 同樣畫面：
   - CPU：GPUI 約是 egui OpenGL 的 **1.5–2.3 倍**（主視窗 15.6% vs 6.8%、高頻 1 萬筆/秒 23.3% vs 9.5%、4 視窗 44.1% vs 27.7%、重圖表 34–38% vs 18–25%）。
   - GPU 3D 使用率：GPUI 約 **2.5–5 倍**（4 視窗 21.7% vs 4.6%）。
   - 「GPUI 用 GPU 換 CPU」在這台 Windows 上**不成立**：GPUI 的 CPU 和 GPU 都比 egui 高。
3. **5 萬列捲動 GPUI 還是會卡**：51 FPS、卡頓 63 次（10-23 是 51.7 FPS、70 次），A2 在 Windows 上幾乎沒改善。
   - **egui OpenGL 也不穩**：兩次合計 6 輪裡有 **4 輪**捲動掉到約 12 FPS、卡頓 112 次（另外 2 輪 60 FPS、0 次；新的這次中位數剛好落在好的那邊）。10-23 那次沒有出現。原因還沒查。
   - **egui wgpu 6 輪都 60 FPS、0 次卡頓**，是捲動唯一穩定的。
4. **記憶體**：一般畫面 GPUI 最省（Working Set 73.3 vs 77.7 MB）；4 視窗和重圖表 egui OpenGL 較省（91 vs 106 MB、86 vs 105–128 MB）。Mac 上那 200 MB 的重圖表問題，**Windows 沒有**。egui wgpu 在 Windows 上記憶體最多（約 180–267 MB）。
5. **單視窗延遲、重圖表 FPS 三邊打平**：高頻每秒 1 千～10 萬筆＋開盤爆量，p50 約 31 ms、p99 約 34 ms，0 掉筆；重圖表 1000 條畫線、100 層全部 60 FPS（這次壓測包不再逾時，有正式數字了）。
6. **比分**（壓測包計分，每個 🏆 算一項）：egui OpenGL 69、GPUI 25、egui wgpu 13、GPUI quad 0、平手 44。

## 門檻判定（白話）

10-24 說好的門檻：「4 視窗 p99 回到 egui 附近（約 35 ms）、Windows 捲動不卡 → 維持 GPUI；修完 CPU／GPU 還是約 2 倍、**而且**多視窗還是落後 → 看盤核心改 egui」。

| 門檻 | Mac（10-25 早上） | Windows（10-25） |
|---|---|---|
| 4 視窗 p99 回到 egui 附近 | 勉強過：35.6 vs 33.6 ms | 勉強過：36.0 vs 33.4 ms |
| 最慢視窗 p99 | 平手：36.4 vs 34.5–36.9 ms | 稍輸：37.3 vs 33.9 ms |
| 捲動不卡 | 過：0 次 | **沒過**：63 次（egui OpenGL 也時好時壞） |
| CPU／GPU 不再約 2 倍 | Mac 和 egui wgpu 差不多，比 egui OpenGL 高 | **沒過**：CPU 1.5–2.3 倍、GPU 2.5–5 倍 |

**結論：延遲過關、效率沒過 → 維持「GPUI 有條件」，不翻盤成 egui，也還不能正式定 GPUI。**
理由：改 egui 的條件是「效率差 **而且** 多視窗落後」，多視窗已經追到差 2–3 ms，所以不成立；但 Windows 的 CPU 約 2 倍、捲動卡頓都沒解決，GPUI 還不能說「過關」。在 PM 的新方向（大部分畫面走 html，GPUI 只做原生殼和少數官方元件）下，這個效率代價影響範圍變小。

## 其他觀察

- **停頓**：Windows 上沒有看門狗 STALL 紀錄。GPUI 4 視窗每輪在開窗後約第 6.5 秒有 1–2 次 0.1–0.29 秒「沒被叫醒」的長幀，egui 沒有紀錄可比。p99 沒受影響，原因還沒查。
- **GPUI 第 2–4 個視窗的第一筆報價晚約 3 秒**：4 視窗時主視窗 0.3 秒就有報價，其他 3 個要到約 3.3 秒（Mac 一樣，約 3.2 秒）；egui 4 個視窗都在 0.2 秒內。延遲是在之後 30 秒量的，表格數字不受影響，但開窗時其他視窗會空白約 3 秒。要查。
- **A3（quad 畫線，`XQ_DRAW_QUADS=1`）在 Windows 也沒用**：FPS 一樣 60，CPU 稍高，Working Set 約 300 MB（預設畫法約 105 MB）。維持預設關。
