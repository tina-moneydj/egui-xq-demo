# 注音 IME 測試說明（egui vs GPUI 股名／代號搜尋框）

## 環境
- 桌面：DISPLAY **:2**（1920×1200；noVNC token "2" → localhost:5902，就是 agent 桌面看到的那個畫面）。wry 版在左上 (10,58)，**不要關**。
- IME：fcitx5 5.x + fcitx5-chewing（新酷音），**標準（大千）鍵盤**，XIM on-the-spot（組字字串直接畫在 app 的輸入框裡，app 自己畫底線）。
- 切換中／英：**Ctrl+Space**（全域共用狀態）。目前狀態可在 shell 查：`fcitx5-remote` → 2=注音、1=英文。
- 測試 app 視窗：內容區左上約 (710,458)，1200×720。**搜尋框**在下半「報價 33 檔」右邊：
  - egui：約 x 812–962、y 845（點 ≈ (880,845)）
  - GPUI：約 x 862–1012、y 845（點 ≈ (930,845)）
- 換 app：`/workspace/bench/ime/run-app.sh egui` 或 `... gpui`（會只關 app.pid 裡那個 PID，再開另一個並擺好位置）。
- egui 版有 `XQ_IME_LOG=1`：每個 IME 事件寫到 /workspace/bench/ime/egui.log（`[ime] Preedit{..}` / `Commit` / `[search] ...`）。

## 測試步驟
1. 點搜尋框（框變亮藍框）。若右下沒有注音狀態，按 **Ctrl+Space** 切到注音。
2. 輸入下列鍵（大千：ㄊ=w ㄞ=9 ˊ=6 ㄐ=r ㄧ=u 一聲=空白 ㄉ=2 ㄢ=0 ˋ=4 ㄏ=c ㄨ=j ㄥ=/ ˇ=3）：

| 目標 | 鍵序 | 注音 |
|---|---|---|
| 台積電 | `w 9 6` `r u Space` `2 u 0 4` | ㄊㄞˊ ㄐㄧ ㄉㄧㄢˋ |
| 鴻海 | `c j / 6` `c 9 3` | ㄏㄨㄥˊ ㄏㄞˇ |

3. 組字中（底線字）**表格不應跳動／搜尋不觸發**；按 **Enter** 送出組字（新酷音的 Enter 只送字，不會被 app 當成「跳轉」）。
4. 送出後下方跳出建議清單（2330 台積電／2317 鴻海）；再按 **Enter**（或點清單）→ 表格選到該列、上方圖表切到該檔；搜尋框清空。
5. 選字修正：新酷音預設可能給「台機電」「紅海」。
   - 台積電：輸入完三字後按 `Left Left Down Down` → 單字候選 → 按 `3`（積）→ Enter。
   - 鴻海：輸入完後按 `Home Down` → 候選 → 按 `4`（鴻）→ Enter。
   - 注意：新酷音會學習，已在自動測試中選過，現在可能直接出「台積電」。
6. 英數：Ctrl+Space 切英文，打 `23` → 清單 8 筆代號開頭 23；↑↓ 移動、Enter 跳轉、Esc 清空。
7. 要觀察／回報的點：
   - 組字底線字是否畫在框內、位置對；游標是否在正確字之間（Left/Right 移動）。
   - 候選窗是否貼著輸入框下方（egui：跟著組字游標；GPUI：在組字字串尾端）。
   - Backspace 刪組字中的注音、Esc 取消組字，是否誤刪已送出的文字。
   - 送字後有無重複字、遺失字；送字時的 Enter 有無誤觸跳轉。
   - 點框外失焦時組字是否被正確結束。
